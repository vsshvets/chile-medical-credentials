# Шаблон сторінки університету

Кожна сторінка — рівно ця структура, у цьому порядку. 250–450 слів української прози
(таблиці й посилання не рахуються). Файл: `universities/<slug>.md`.

```markdown
# {Офіційна іспанська назва}

[← до списку університетів](README.md) · [← на головну](../README.md)

> {Один рядок: що це за університет і де він. Без реклами.}

| | |
|---|---|
| **Тип** | {державний / приватний (CRUCH) / приватний} |
| **Місто (регіони)** | {…} |
| **Студентів медицини (2026)** | {matrícula total} |
| **Набір 1-го курсу (2026)** | {matrícula primer año} |
| **Кампусів з медициною** | {n} |
| **Акредитація програми (CNA)** | {N років, до ДД-ММ-РРРР} або «немає в реєстрі CNA» |
| **Медичний факультет** | [{назва}]({url}) |
| **Декан** | {ім'я або «не вдалося підтвердити»} |
| **Ревматологія** | {є підрозділ / немає / не підтверджено} · {є ординатура / немає} |
| **Вакансії** | [{сторінка конкурсів}]({url}) |

## Про факультет

{2–3 абзаци української прози. Максимум 400 символів на абзац. Тільки факти з даних.
Коли заснований, де, з якою лікарнею працює, чим вирізняється. Без прикметників,
скопійованих із сайту університету.}

## Ревматологія

{1 абзац: чи є підрозділ, чи є ординатура з ревматології, як він називається іспанською.
Якщо не підтверджено — так і написати.}

## Чи наймають

{1 абзац: що зараз відкрито (з датою перевірки), що кажуть вимоги про іноземний диплом
і громадянство. Якщо нічого не відкрито — так і написати.}

## Джерела

- [{що саме підтверджує}]({url})
```

## Правила

1. **Назви іспанською.** Ніколи не транслітеруй назву університету, факультету, лікарні,
   міста чи посади, яку вона писатиме в анкеті. Кирилиця — для читання, іспанська — для документів.
2. **Числа беруться з `data/medical-schools.csv`**, а не з JSON дослідження і не з голови.
3. **«не вдалося підтвердити»** — це правильна відповідь. Ніколи не вигадуй декана, e-mail,
   підрозділ чи вакансію.
4. **Дата перевірки** обов'язкова там, де йдеться про відкриті вакансії: «станом на 3 вересня 2026».
5. **Жодних абзаців довших за 400 символів.**
6. **Без маркетингових прикметників** — ані своїх, ані скопійованих із сайту університету.
7. Терміни — за замком термінології `data/terms.csv`.
