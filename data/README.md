## medical-schools.csv — довідник колонок

| Колонка | Значення |
|---|---|
| `slug` | Ідентифікатор для посилання на сторінку університету |
| `institution` | Офіційна іспанська назва |
| `short_name` | Загальновживана абревіатура (UChile, UC, USACH) |
| `sies_name` | Назва так, як вона стоїть у файлі SIES (для звірки) |
| `type` / `subtype` | Класифікація MINEDUC: CRUCH чи приватний, державний чи ні |
| `is_state` | `yes` — державний університет. **Важливо:** саме державні університети отримали право визнавати іноземні дипломи після 17 серпня 2026 року |
| `is_cruch` | Належність до Consejo de Rectores |
| `regions` | Регіони, де є програма з медицини |
| `campuses_with_medicina` | Скільки кампусів навчають медицині |
| `matricula_total_2026` | **Усі студенти медицини, всі курси, 2026 рік** |
| `matricula_primer_ano_2026` | **Зараховані на перший курс 2026 року** |
| `women_2026` / `men_2026` / `pct_women` | Розподіл за статтю |
| `institutional_accreditation` | Статус акредитації університету за даними SIES |
| `programme_accreditation` | Статус акредитації самої програми з медицини |
| `duration_semesters` | Тривалість навчання |
| `new_programme_2026` | `yes` — програма стартувала 2026 року, тому загальна кількість дорівнює першому курсу |
| `source`, `source_url`, `source_date` | Звідки взято числа |

### ⚠️ Три показники, які постійно плутають

| Показник | Що це | Що це НЕ |
|---|---|---|
| **matrícula total** | Усі студенти програми, всі курси разом | не річний набір |
| **matrícula de primer año** | Скільки зарахували на перший курс цього року | не кількість оголошених місць |
| **vacantes ofrecidas** | Скільки місць університет оголосив | не скільки заповнив |

Цей файл містить перші два. Третій публікується окремо (DEMRE) і в цей набір не входить.

## Джерело

**SIES / MINEDUC, «Matrícula 2026»**, опублікований 10 липня 2026 року:
<https://www.mifuturo.cl/bases-de-datos-de-matriculados/>

Прямий файл: `Matricula_2026_WEB_10_07_2026.zip` (усередині — RAR, усередині — CSV у кодуванні latin-1,
роздільник `;`, 15 901 рядок, 58 колонок).

## Як перебудувати

```bash
# 1. завантажити набір даних у raw/sies/  (raw/ не потрапляє в git)
curl -L -o raw/sies/mat2026.zip \
  https://www.mifuturo.cl/wp-content/uploads/2026/07/Matricula_2026_WEB_10_07_2026.zip
cd raw/sies && unzip -o mat2026.zip && bsdtar -xf *.rar && cd ../..

# 2. перебудувати таблицю
python3 scripts/build_schools.py     # -> data/medical-schools.csv
python3 scripts/render_tables.py     # -> таблиця для README
```

## Відомі межі

- Дані про зарахування — за 2026 рік. Дані за 2027-й з’являться в липні 2027-го.
- Акредитація в наборі SIES позначена лише як `ACREDITADA`, **без кількості років і рівня**.
  Кількість років і рівень акредитації беруться окремо з реєстру CNA, бо саме від них залежить,
  чи має університет право визнавати іноземні дипломи.
- Набір охоплює лише програми рівня `Pregrado` зі спеціальності «Medicina». Ветеринарна медицина,
  бакалаврати з біомедицини та інші суміжні програми виключені навмисно.
